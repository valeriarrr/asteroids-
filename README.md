## Описание проекта

Программа представляет собой игру в астероиды. С помощью клавиаруты играющий может двигать самолет, стрелять по астероидам. Всего дано 3 попытки, за каждое попадание по астероиду, играющий полуает 1 очко. При 3 попаданиях самолета на астероид, игра начинается заново.

## Функциональные возможности

### Основной функционал
- 📐 Движение самолета через стрелки на клавиатуре
- 🔍 Стрельба по астероидам при нажатии пробела
- ▶️ Завершение игры при попадании 3 раз самолета на астероид (достижения сбрасываюся, начинается новая игра)

### Дополнительный функционал
- 🎨 Смена темы игры (дневная и ночная)

## Требования к системе
- **Python:** 3.10.11 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** `tkinter`

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/valeriarrr/pink_snake_mimimi.git
cd pink_snake_mimimi
```

### 2. Создание и активация виртуального окружения
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```
